cofy-x builds open-source software for people and AI agents to work together. Our work spans shared workspaces, practical tools, and execution infrastructure.

The name **cofy-x** stands for **Coordination Fly X**: people and AI coordinating to turn ideas into working, open systems.

## What we explore

- **Workspaces & collaboration:** shared context, creation, and review for people and agents.
- **Execution infrastructure:** isolated execution, reproducible environments, and dependable foundations for agent workloads.
- **Tools & experiments:** practical developer tools and explorations in interaction, visualization, and new ways of working.

[Browse all repositories →](https://github.com/orgs/cofy-x/repositories?type=public)

## Get involved

Questions, ideas, and contributions are welcome in each project's repository. Start with its README for current documentation and ways to contribute.
