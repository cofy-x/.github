  <strong>Open-source tools and infrastructure for people and AI agents.</strong>

cofy-x builds software for people and AI agents to work together. Our projects span shared workspaces, developer tools, and the execution infrastructure behind them: from team discussions and terminal workflows to isolated sandboxes and reproducible image builds.

The name **cofy-x** stands for **Coordination Fly X**: people and AI coordinating to turn ideas into working, open systems.

## Explore the projects

### Workspaces & collaboration

- [**Camp**](https://github.com/cofy-x/camp) — a shared workspace for team discussions, files, Agent execution, and human review, powered by independent Linux runners.
- [**AXV**](https://github.com/cofy-x/axv) — an experimental personal cloud workstation for documents, terminals, coding agents, and virtual machines.
- [**Elyro**](https://github.com/cofy-x/elyro) — local Linux workspaces for developers and coding agents: edit on Mac, build and test in Linux.
- [**Deck**](https://github.com/cofy-x/deck) — a desktop cockpit for local AI sandboxes, with a visible Linux desktop and editor or terminal handoff.

### Execution infrastructure

- [**Axern**](https://github.com/cofy-x/axern) — isolated execution for Agent evaluation, training, and data synthesis, with gVisor/runsc and Go, Python, and TypeScript SDKs.
- [**Kova**](https://github.com/cofy-x/kova) — cloud-neutral image build execution, from immutable sources to verified OCI manifest digests.
- [**Axrun**](https://github.com/cofy-x/axrun) — a recoverable evaluation runner built on Axern, connecting inference, candidate artifacts, and independent verification.

### Tools & experiments

- [**DSH Console**](https://github.com/cofy-x/dsh-console) — a DeepSeek Harness terminal workbench with durable sessions, structured tools, approvals, and plan views. Related projects explore [automation](https://github.com/cofy-x/dsh-automation) and [verification](https://github.com/cofy-x/dsh-as-a-verifier).
- [**Peek LLM**](https://github.com/cofy-x/peek-llm) — interactive visual explanations of language model concepts.
- [**Pixel to ASCII**](https://github.com/cofy-x/pixel-to-ascii) and [**Three.js X Space**](https://github.com/cofy-x/threejs-x-space) — experiments in terminal art and interactive graphics.

## Get involved

- Start with a project's README for its current status, setup, and supported workflows.
- Report bugs, propose features, or contribute in the relevant repository.
- Privately report vulnerabilities through the [central security advisory form](https://github.com/cofy-x/.github/security/advisories/new).

Contributions, thoughtful feedback, and curious exploration are welcome.
